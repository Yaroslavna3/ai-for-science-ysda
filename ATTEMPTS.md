# Журнал попыток ДЗ 2

Правило: на одну подцель допускается не более трёх попыток. После каждого неуспеха фиксируются ошибка и один конкретный параметр, который изменится в следующей попытке; нельзя повторять тот же запуск без изменения условий. Goose получает ровно одну попытку на G5.

| № | Подцель | Исполнитель | Запрос/изменение | Результат | Следующий шаг |
|---|---|---|---|---|---|
| G5-1 | Реализация классификатора выбросов | Goose/AI4Science, Qwen3.6-35b-a3b/latest, сессия `20261108_1` | Реализовать правило относительно медианы и запустить только два фокус-теста | Изменён только `src/boyle_core.py`; оба теста прошли после установки отсутствовавшей `hypothesis`. Реализация первоначально не проверяла допустимость порога и положительность pV; эти проверки добавлены Codex отдельно, не приписываются Goose. | Единственная сессия Goose завершена; повторов Goose не делали. Codex добавил проверки некорректных входов и затем запускает полный набор. |

Точный запрос Goose: «Подцель G5 из SUBGOALS.md. Реализуй только функцию classify_outliers в src/boyle_core.py: флаг должен быть abs(value/median - 1) > threshold, threshold по умолчанию 0.10; входные pV и threshold проверь на пустую/некорректный диапазон и нечисловые конечные значения с ValueError. Запусти только тесты checks/test_hw2_properties.py, относящиеся к classify_outliers (масштабная инвариантность и точная граница). Меняй только src/boyle_core.py. Не меняй тесты, данные, METHOD.md, AGENTS.md, diary.md и результаты. Не коммить. В конце сообщи кратко, какие строки менял и результат focused-тестов.»

Фактический запуск: первый focused pytest не собрался (`ModuleNotFoundError: hypothesis`); Goose установил `hypothesis` в пользовательский Python, после чего повторил два теста. `test_outlier_flags_are_scale_invariant` — PASSED (100 Hypothesis examples); `test_values_exactly_on_threshold_are_not_outliers` — PASSED; pytest сообщил `2 passed in 2.15s`. Первые попытки редактирования не применились, агент затем записал файл целиком. Дополнительная проверка пустого списка дала ожидаемый `ValueError`; попытка самостоятельной проверки сначала ошиблась из-за импорта без `src` в `sys.path`, затем была повторена с путём. Одну Goose-сессию считаем использованной; повторять Goose ради улучшения guard-проверок не будем.

Полные property-прогоны, seed-повторы и мутационные проверки пока не выполнены; добавлять их результаты до фактического запуска нельзя.
