# AGENT.md — учебный проект «Изотермический процесс»

## Цель проекта
Проверить по измерениям, выполняется ли закон Бойля–Мариотта (p·V = const
при постоянной температуре), и оценить разброс p·V.

## Данные
- `data/measurements.csv`: `volume_l` (л), `pressure_kpa` (кПа), `temperature_k` (К).
- Исходные данные не изменять. Производные файлы — в `results/`.

## Как работать
- Расчёты — скриптами Python в `src/`, результаты — в `results/`.
- Каждый вывод сопровождается способом проверки: чем и как его можно
  перепроверить независимо.

## Журнал
- В `diary.md` после каждой задачи: дата, запрос, что сделано, результат,
  способ проверки.

## Запрещено
- Удалять и перезаписывать `data/`.
- Выдавать вывод без указания, как он проверен.
