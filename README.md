# AI for Science — ШАД

Учебный репозиторий по курсу «ИИ-ассистенты для исследователя» (ШАД). В проекте на примере изотермических измерений проверяется закон Бойля–Мариотта, а также демонстрируется работа агента по инструкции `AGENTS.md` с независимой автоматической проверкой.

## Что внутри

- `AGENTS.md` — цель агента, формат результата, ограничения и критерии остановки.
- `checks/check.py` — независимая проверка выходных файлов.
- `data/measurements.csv` — исходные измерения при постоянной температуре.
- `src/analyze_boyle.py` — анализ для первой недели.
- `results/` — результаты первой и второй недель.
- `diary.md` — журнал экспериментов и запусков агентов.
- `WEEK1_REPORT.md` — отчёт по первой неделе.
- `INDEX.md` — навигация по проекту и локальному контексту.
- `memory/L1.md`, `memory/L2.md`, `memory/L3.md` — три уровня сжатия научной статьи о синтезе нанодисперсного Co3O4 и микроплоттерной печати.
- `library/simonenko_et_al_2022_co3o4.pdf` — статья-источник; номера страниц оригинала указаны в L2.

## Результаты недели 2

По 12 измерениям рассчитано произведение `pV`. Строка 7 обнаружена как выброс; для остальных измерений среднее `pV` составляет 249.318 кПа·л, относительный разброс — 1.01%.

Проверка результата:

```powershell
python checks/check.py
```

При успехе проверка сообщает `принято` и завершается с кодом `0`. Нужен Python 3. Файл проверки и исходные данные защищены от записи атрибутом Windows «только чтение»; перед изменением этих файлов проверьте требования задания.

## Контекст недели 3

В `memory/` хранится каскадное сжатие статьи Симоненко и соавторов (2022): реферат по разделам (L1), семь тезисов со сверкой страниц оригинала (L2) и однострочное резюме (L3).
