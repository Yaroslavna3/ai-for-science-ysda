# Заметки к онтологии Co3O4-проекта

## Сессия 1 (2026-10-22)

### Цель
Создать онтологическую схему, связывающую классы, отношения и факты
из статьи Симоненко и соавт. (2022) с файловой структурой проекта.

### Структура ontology.yaml (сессия 1)
- **classes** — 5 классов: Задача, Файл, Метод, Материал, Параметр.
  Обязательные «Задача» и «Файл» включены.
- **relations** — 7 отношений с явными domain/range.
- **attributes** — 4 атрибута; `status` — enum с тремя значениями.
- **rules** — 3 проверяемых правила (R1–R3).
- **concepts** — 7 понятий, каждое помечено как `class` или `instance`.
- **competency_questions** — 4 вопроса проекта.

### Различение класса и экземпляра
| Понятие | Kind | Обоснование |
|---|---|---|
| Co3O4 | class | Класс материалов, а не единичный объект |
| химическое_осаждение | class | Тип метода, а не конкретный запуск |
| микроплоттерная_печать | class | Тип технологии |
| эффект_кофейного_пятна | instance | Конкретный наблюдаемый феномен |
| нитрат_кобальта | instance | Конкретное химическое вещество |
| гидрат_аммиака | instance | Конкретное химическое вещество |
| этиленгликоль | instance | Конкретное химическое вещество |

### Источники фактов
Все факты взяты из `library/simonenko_et_al_2022_co3o4.pdf`
и сверены с `memory/L1.md` / `memory/L2.md`.
Новые факты не добавляются.

### Ограничения
- Не приписываем статье испытания готового суперконденсатора.
- Не смешиваем размер ОКР (17 ± 2 нм, РФА) с размером частиц (23 ± 2 нм, ПЭМ).
- Не дополняем условия синтеза параметрами, отсутствующими в оригинале.

## Сессия 2 (2026-10-22) — финализация

### Изменения
1. **Перемещение схемы**: `ontology/ontology.yaml` → `ontology.yaml` (корень проекта).
2. **Иерархия классов**: все классы получили `parent`-ссылки.
   Корень — `ПроектнаяСущность`, разветвление на `НаучнаяСущность` и `АртефактПроекта`.
3. **Добавлен `instance_of`**: каждый экземпляр в `concepts` ссылается на родительский класс.
4. **Удалён `ontology/validate.py`**: скрипт не работал (жёстко захардкожен путь).
5. **Версия схемы**: `0.2`.
