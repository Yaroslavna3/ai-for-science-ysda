# L3

Химическое осаждение и прокаливание при 400 °C дают наночастицы Co3O4 (17 ± 2 нм по РФА, 23 ± 2 нм по ПЭМ), пригодные для микроплоттерной печати планарных островковых структур без эффекта «кофейного пятна»; применение в планарных суперконденсаторах предложено как перспектива, но не проверено испытанием готового устройства.
